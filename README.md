# pmg-goals

A four-phase goal system built on a missionary planning framework — because missionaries hit numbers with zero budget and total commitment.

## Where this comes from

*Preach My Gospel* Chapter 8 is the planning manual used by tens of thousands of full-time missionaries: **Set Goals and Make Plans → Record and Schedule → Act → Review and Follow Up.** I adapted it for business goals after using it firsthand. It works because it was designed for people whose outcomes depend entirely on other people's agency — which describes sales, entrepreneurship, and most of life.

## The twist

Two things most goal frameworks miss, baked in here:

1. **Inputs vs. outcomes.** Revenue, signed clients, and yeses depend on other people. You don't set goals on those — you set goals on your *input levers*: conversations had, messages sent, demos built, material created. The framework forces you to separate the two before anything gets scheduled.
2. **The stretch check.** A goal that doesn't require faith — that you could hit on autopilot — isn't a goal, it's a forecast. Every goal gets tested: does this stretch you or just describe you?

## Install

```bash
git clone https://github.com/nradawg/pmg-goals.git
cd pmg-goals && bash install.sh
```

## Use

```
/pmg-goals
```

It walks you through whichever phase you're in, and picks up where you left off next session. Goals live in a plain markdown file you own.

## The four phases

1. **Set Goals & Make Plans** — purpose first, then the big goal, then small goals, then the inputs-vs-outcomes split
2. **Record & Schedule** — where the work lives, daily action, weekly action, next-24-hours action
3. **Act** — do the inputs; the system only tracks what you control
4. **Review & Follow Up** — what moved, what didn't, realign without resetting
